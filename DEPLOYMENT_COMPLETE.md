## 📦 СОЗДАННЫЕ ФАЙЛЫ

### Конфигурационные файлы (3)

1. **`.env.hetzner`** ⭐ ОТРЕДАКТИРОВАТЬ
   - Переменные окружения для production
   - Нужно заменить домены и Telegram токен
   - Будет скопирован на сервер как `.env`

2. **`ecosystem.config.js`**
   - Конфигурация PM2 для управления процессами
   - Настройка для 2 приложений (API и Frontend)
   - Auto-restart и логирование

3. **`nginx.conf`** ⭐ ОТРЕДАКТИРОВАТЬ
   - Конфигурация Nginx reverse proxy
   - HTTP → HTTPS редирект
   - SSL конфигурация
   - WebSocket поддержка
   - Нужно заменить домены

### Скрипты развертывания (5)

1. **`deploy.sh`** ⭐ ГЛАВНЫЙ - ЗАПУСТИТЬ ОДИН РАЗ
   - Полное автоматическое развертывание
   - Обновляет систему
   - Устанавливает Node.js, Nginx, PM2, Certbot
   - Клонирует Git репозиторий
   - Собирает приложение
   - Создает SSL сертификат
   - Запускает приложение

2. **`update.sh`**
   - Безопасное обновление приложения
   - Создает резервную копию перед обновлением
   - Git pull → npm install → npm build → restart

3. **`backup.sh`**
   - Создание резервных копий
   - Архивирует приложение
   - Сохраняет .env отдельно
   - Исключает node_modules для экономии места

4. **`check-status.sh`**
   - Проверка здоровья приложения
   - API health
   - WebSocket статус
   - Системные ресурсы
   - SSL сертификат

5. **`security-setup.sh`**
   - Настройка безопасности
   - Автоматические системные обновления
   - Автоматические резервные копии
   - SSH затвердение
   - Fail2ban установка

```
Отредактируйте 2 файла:
1. .env.hetzner (домены, токены)
2. deploy.sh (REPO_URL, DOMAIN)
```

### Шаг 3: Запустите развертывание
```bash
# На сервере Hetzner
chmod +x deploy.sh
bash deploy.sh
```

### Шаг 4: Финализируйте
```bash
# На сервере
nano /home/cave-game/.env
# Отредактировать реальные значения

pm2 restart ecosystem.config.js
# Проверить: https://your-domain.com
```

## 🔄 ЖИЗНЕННЫЙ ЦИКЛ ПРИЛОЖЕНИЯ

```
deploy.sh (запустить один раз)
    ↓
Приложение работает на production
    ├─ Ежедневно (2 AM): Системные обновления
    ├─ Еженедельно (вс 3 AM): Обновление приложения
    ├─ Ежедневно (4 AM): Резервная копия
    ├─ Ежедневно (5 AM): Очистка старых бэкапов
    └─ 24/7: PM2 следит чтобы приложение было живо

При обновлении кода:
    ├─ Вариант 1: git push → автоматически обновляется
    └─ Вариант 2: bash update.sh → вручную обновляет

При проблемах:
    ├─ pm2 logs → просмотреть логи
    ├─ pm2 restart → перезагрузить
    └─ bash check-status.sh → проверить здоровье
```
