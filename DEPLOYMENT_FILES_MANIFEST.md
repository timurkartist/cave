# 📦 Полный список файлов для развертывания на Hetzner

## 📍 Расположение всех файлов

Все файлы находятся в корневой папке проекта: **`d:\cave-game\`**

---

## 📋 Конфигурационные файлы

### 1. `.env.hetzner`
**Назначение**: Переменные окружения для production  
**Размер**: ~1 KB  
**Действие**: Скопировать на сервер, переименовать в `.env`, отредактировать значения  
**Содержит**:
- Telegram бот токен
- API URLs
- WebSocket конфигурация
- Логирование

**Использование**:
```bash
# На локальной машине
scp .env.hetzner root@SERVER_IP:/tmp/

# На сервере
cp /tmp/.env.hetzner /home/cave-game/.env
nano /home/cave-game/.env
# Редактировать реальные значения
```

---

### 2. `ecosystem.config.js`
**Назначение**: Конфигурация PM2 для управления процессами  
**Размер**: ~2 KB  
**Действие**: Скопировать на сервер как есть  
**Содержит**:
- Настройки для cave-game-api процесса
- Настройки для cave-game-frontend процесса
- Логирование
- Auto-restart конфигурация
- Кластерный режим

**Использование**:
```bash
# На сервере
pm2 start ecosystem.config.js
pm2 status
pm2 logs
```

---

### 3. `nginx.conf`
**Назначение**: Конфигурация веб-сервера Nginx и SSL  
**Размер**: ~5 KB  
**Действие**: Скопировать на сервер, редактировать домены  
**Содержит**:
- HTTP → HTTPS редирект
- SSL конфигурация
- Reverse proxy к приложению
- WebSocket поддержка
- Gzip компрессия
- Caching правила
- Security headers

**Использование**:
```bash
# Проверить синтаксис
nginx -t

# Перезагрузить конфиг
systemctl reload nginx
```

---

## 🔧 Скрипты развертывания

### 1. `deploy.sh` ⭐ ГЛАВНЫЙ
**Назначение**: Полное развертывание приложения  
**Размер**: ~8 KB  
**Действие**: Запустить один раз на новом сервере  
**Выполняет**:
1. Обновление системы
2. Установка Node.js 20
3. Установка Nginx
4. Установка PM2
5. Установка Certbot (SSL)
6. Клонирование Git репозитория
7. Установка npm зависимостей
8. Сборка фронтенда
9. Создание SSL сертификата
10. Конфигурация Nginx
11. Запуск приложения через PM2

**Использование**:
```bash
# На сервере
chmod +x deploy.sh
bash deploy.sh
```

**Время выполнения**: 5-10 минут

---

### 2. `update.sh`
**Назначение**: Безопасное обновление приложения  
**Размер**: ~3 KB  
**Действие**: Запускать при обновлении кода  
**Выполняет**:
1. Создание резервной копии
2. Получение последнего кода из Git
3. Установка новых зависимостей
4. Сборка фронтенда
5. Перезапуск приложения
6. Проверка здоровья

**Использование**:
```bash
# На сервере
cd /home/cave-game
bash update.sh
```

**Альтернатива**: `git push origin main` (автоматическое обновление через Git hook)

---

### 3. `backup.sh`
**Назначение**: Создание резервной копии приложения  
**Размер**: ~1.5 KB  
**Действие**: Запускать вручную или по расписанию  
**Выполняет**:
1. Архивирует приложение в tar.gz
2. Отдельно сохраняет .env (опционально зашифрованный)
3. Исключает node_modules и dist для экономии места

**Использование**:
```bash
# На сервере
bash backup.sh /home/cave-game/backups
```

**Файл**: `/home/cave-game/backups/cave-game_YYYYMMDD_HHMMSS.tar.gz`

**Восстановление**:
```bash
tar -xzf cave-game_20240101.tar.gz -C /
pm2 restart ecosystem.config.js
```

---

### 4. `check-status.sh`
**Назначение**: Проверка здоровья приложения  
**Размер**: ~2 KB  
**Действие**: Запускать регулярно для мониторинга  
**Проверяет**:
- API health endpoint
- Frontend доступность
- WebSocket соединение
- PM2 процессы
- Системные ресурсы (память, диск)
- SSL сертификат

**Использование**:
```bash
# На сервере
bash check-status.sh your-domain.com
```

**Вывод**: ✓/✗ статусы для каждого компонента

---

### 5. `security-setup.sh`
**Назначение**: Настройка безопасности и автоматизации  
**Размер**: ~3.5 KB  
**Действие**: Запустить один раз после deploy.sh  
**Выполняет**:
1. Настраивает автоматические системные обновления
2. Настраивает еженедельное обновление приложения
3. Настраивает ежедневные резервные копии
4. Настраивает очистку старых резервных копий
5. Затвердевает SSH конфигурацию
6. Устанавливает Fail2ban (защита от атак)

**Использование**:
```bash
# На сервере
bash security-setup.sh
```

**Запланированные задачи**:
- 2:00 AM - Системные обновления
- 3:00 AM (воскресенье) - Обновление приложения
- 4:00 AM - Резервная копия
- 5:00 AM - Очистка старых бэкапов

## 🔄 Как использовать эти файлы на сервере

```bash
# 1. На локальной машине копируем все файлы на сервер
scp deploy.sh .env.hetzner ecosystem.config.js nginx.conf security-setup.sh root@SERVER_IP:/tmp/

# 2. На сервере переходим в /tmp
ssh root@SERVER_IP
cd /tmp

# 3. Запускаем главный скрипт
chmod +x deploy.sh
bash deploy.sh
```

**И всё! Скрипт делает всё остальное автоматически.**

---

## 🎯 Файлы вместе работают так:

```
deploy.sh (главный скрипт)
├─ Копирует: .env.hetzner → /home/cave-game/.env
├─ Копирует: ecosystem.config.js → /home/cave-game/
├─ Копирует: nginx.conf → /etc/nginx/sites-available/
├─ Настраивает: PM2
├─ Настраивает: Nginx
├─ Настраивает: SSL (Certbot)
└─ Запускает: Приложение

Затем для обновления:
update.sh
└─ Использует: .env, ecosystem.config.js из /home/cave-game/

Для мониторинга:
check-status.sh
└─ Проверяет всё что настроили

Для безопасности:
security-setup.sh
└─ Добавляет автоматизацию и защиту
```
