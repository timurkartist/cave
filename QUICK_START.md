# ⚡ Быстрый старт - запуск приложения в сети

## Вариант А: Вы просто хотите поиграть (самый простой)

### Шаг 1: Откройте ПЕРВЫЙ терминал (Фронтенд)
```bash
npm run dev
```
Ждите пока напишет `Local: http://localhost:3000/`

### Шаг 2: Откройте ВТОРОЙ терминал (Бэкенд)
```bash
node server.js
```
Ждите пока напишет `✅ Server started on port 3001`

### Шаг 3: Откройте ТРЕТИЙ терминал (Бот)
```bash
node bot.js
```

### Шаг 4: Откройте ЧЕТВЁРТЫЙ терминал (ngrok)
```bash
npm run start:ngrok
```

**Готово!** Когда напишет `Share this URL with other players: https://...` - скопируйте этот URL и дайте другим.

---

## Вариант B: Кто-то будет присоединяться через ngrok (для других игроков)

Сделайте всё как выше, потом:

1. **Скопируйте URL из Шага 4** (видно в терминале)
2. **Дайте друзьям этот URL**
3. **Они открывают его в браузере** (на своем устройстве, в интернете)
4. **Всё работает!** WebSocket подключится автоматически

---

## Вариант C: Если одного терминала недостаточно

Если у вас недостаточно окон/терминалов, можно запустить в одном:

```bash
npm run dev:all
```

Потом в отдельном:
```bash
npm run start:ngrok
```

## 📱 Как присоединяются другие

1. Получают от вас URL: `https://cave.ngrok.app`
2. Открывают в браузере (рабочем столе, планшете, телефоне)
3. Вводят имя и выбирают персонажа
4. **Готово!** Они в вашей игре

## 🚨 Если что-то упало

### Если бэкенд не запускается:
```bash
# Убейте всё что торчит
taskkill /F /IM node.exe

# Потом заново
node server.js
```

### Если WebSocket не подключается:
1. Проверьте что **оба туннеля запущены** (в терминале ngrok видно 2 туннеля)
2. **Перезагрузите страницу** в браузере (F5)
3. Откройте DevTools (F12) → Console - ищите ошибки

### Если ngrok не работает:
```bash
# Убедитесь что токен есть
Get-Content .env | grep NGROK_AUTHTOKEN
```

Если нет - получите его здесь: https://dashboard.ngrok.com/get-started/your-authtoken
