## Этап 1: Подготовка сервера

### На локальной машине

- [ ] Отредактирован `.env.hetzner` с реальными значениями:
  - [ ] `TELEGRAM_BOT_TOKEN` - ваш реальный токен
  - [ ] `your-domain.com` - ваше доменное имя
- [ ] Отредактирован `deploy.sh`:
  - [ ] `REPO_URL` - ваш GitHub репозиторий
  - [ ] `DOMAIN` - ваше доменное имя
- [ ] Код закоммичен и отправлен в GitHub:
  ```bash
  git add .
  git commit -m "Add Hetzner deployment files"
  git push origin main
  ```

### На Hetzner

- [ ] Создан новый сервер:
  - [ ] Image: Ubuntu 22.04
  - [ ] Type: CPX11 (2 CPU, 2GB RAM)
  - [ ] Получен IP адрес: `___________`
  
- [ ] Доменное имя настроено:
  - [ ] A record указывает на IP Hetzner
  - [ ] DNS обновился (может занять 5-30 минут)
  - [ ] Проверка: `nslookup your-domain.com`

## Этап 2: Развертывание

### SSH доступ

- [ ] SSH подключение работает:
  ```bash
  ssh root@YOUR_SERVER_IP
  ```

### Загрузка файлов

- [ ] Загружены скрипты на сервер:
  ```bash
  scp deploy.sh root@YOUR_SERVER_IP:/tmp/
  scp .env.hetzner root@YOUR_SERVER_IP:/tmp/
  scp ecosystem.config.js root@YOUR_SERVER_IP:/tmp/
  scp nginx.conf root@YOUR_SERVER_IP:/tmp/
  scp security-setup.sh root@YOUR_SERVER_IP:/tmp/
  ```

### Запуск развертывания

- [ ] Выполнен скрипт `deploy.sh`:
  ```bash
  ssh root@YOUR_SERVER_IP
  cd /tmp
  chmod +x deploy.sh
  bash deploy.sh
  ```
  ⏳ Подождите 5-10 минут пока скрипт выполняется
  
- [ ] Развертывание завершилось без ошибок
- [ ] Появилось сообщение: "✨ Deployment complete!"

## Этап 3: Финальная настройка

### Конфигурация приложения

- [ ] Отредактирован `.env` на сервере:
  ```bash
  nano /home/cave-game/.env
  ```
  Проверить и обновить:
  - [ ] `TELEGRAM_BOT_TOKEN` - ваш реальный токен
  - [ ] `VITE_API_URL` - ваше доменное имя

  - [ ] `FRONTEND_URL` - ваше доменное имя
  - [ ] `BACKEND_URL` - ваше доменное имя
  
  (Нажать Ctrl+O, Enter, Ctrl+X для сохранения)

### Перезапуск приложения

- [ ] Приложение перезапущено:
  ```bash
  pm2 restart ecosystem.config.js
  ```
- [ ] Подождано 3-5 секунд
- [ ] Проверен статус:
  ```bash

  # Оба процесса должны быть "online"
  ```

### SSL сертификат

- [ ] Отображает: `your-domain.com`

Если что-то не работает:

- [ ] Проверить логи: `pm2 logs`
- [ ] Перезапустить: `pm2 restart ecosystem.config.js`
- [ ] Перезагрузить Nginx: `systemctl restart nginx`
- [ ] Обновить .env: `nano /home/cave-game/.env` + `pm2 restart`
- [ ] Обновить DNS: Иногда требуется 5-30 минут
- [ ] Проверить порты: `netstat -tlnp | grep node`
