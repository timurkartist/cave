## 🚀 Как запустить ngrok CLI

### Способ 1: PowerShell скрипт (РЕКОМЕНДУЕТСЯ)
```powershell
.\start-ngrok-cli.ps1
```

### Способ 2: Батник (двойной клик)
```
start-ngrok-cli.bat
```

### Способ 3: Вручную (PowerShell)
```powershell
$env:Path += ";C:\ngrok"
ngrok http 3000
```

### Способ 4: Вручную (CMD)
```cmd
set PATH=%PATH%;C:\ngrok
ngrok http 3000
```

## 📊 Сравнение: Node.js скрипт vs ngrok CLI

| Функция | Node.js (`npm run start:ngrok`) | ngrok CLI (`ngrok http 3000`) |
|---------|--------------------------------|-------------------------------|
| Установка | Встроено (npm) | Требует установки CLI |
| Туннелей | 2 (3000 + 3001) | 1 туннель |
| Auto .env | ✅ Да | ❌ Нет (нужно вручную) |
| Сложность | Проще | Проще |
| Production | ⚠️ Не рекомендуется | ✅ Рекомендуется |
| Custom domain | ❌ Не работает бесплатно | ❌ Не работает бесплатно |

## 🔑 Чему вы научились

1. **Как скачать и установить ngrok CLI на Windows**
   - Автоматическая установка через PowerShell
   - Распаковка в системную папку
   - Добавление в PATH

2. **Как настроить authtoken**
   - `ngrok config add-authtoken`
   - Хранится в `~/.ngrok/ngrok.yml`

3. **Как запустить туннель**
   - `ngrok http <PORT>`
   - Получение публичного URL
   - Проверка статуса

4. **Когда использовать что**
   - Node.js для разработки (удобнее)
   - CLI для production (стабильнее)

## 🐛 Отладка

### ngrok не запускается:
```bash
# Проверьте версию
ngrok --version

# Проверьте authtoken
ngrok config check
```

### Туннель падает:
- Убедитесь что localhost:3000 доступен
- Проверьте интернет соединение
- Посмотрите веб-интерфейс: `http://127.0.0.1:4040`

### Custom domain не работает:
- Custom domains требуют **PRO аккаунт** ngrok ($5+/месяц)
- Без PRO будут только случайные домены
