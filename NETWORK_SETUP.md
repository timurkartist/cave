# 🌐 Сетевая конфигурация приложения

## Анализ проблем (честный диагноз)

### Критические ошибки которые были исправлены:

1. **❌ Node.js не может выполнять TypeScript**
   - `server.js` импортировал `types.ts` напрямую
   - Node.js не имеет встроенной поддержки TypeScript
   - **Решение:** Создан `types.js` с JavaScript экспортами

2. **❌ ngrok проксирует только HTTP, а не WebSocket**
   - Старый конфиг создавал только ОДН туннель на порт 3000 (Vite)
   - Когда клиент пытался подключиться к WebSocket через ngrok, это шло на Vite
   - Vite не проксирует WebSocket правильно в dev режиме
   - **Решение:** Создано ДВА отдельных туннеля ngrok:
     - Туннель 1: порт 3000 (фронтенд)
     - Туннель 2: порт 3001 (бэкенд с WebSocket)

3. **❌ Неправильная архитектура проекта**
   - Дублированные папки: `/gpt/`, `/check/` содержат копии кода
   - Создает путаницу и конфликты импортов
   - **Рекомендация:** Удалить дублированные папки

## 🚀 Как запустить приложение

### Вариант 1: Разбор по отдельности (для разработки)

Откройте **ТРИ отдельных терминала**:

**Терминал 1 - Фронтенд:**
```bash
npm run dev
```
Откроется на `http://localhost:3000`

**Терминал 2 - Бэкенд + WebSocket:**
```bash
node server.js
```
Будет на `http://localhost:3001` с WebSocket на `ws://localhost:3001`

**Терминал 3 - Telegram бот:**
```bash
node bot.js
```

**Терминал 4 - ngrok туннели (в отдельном):**
```bash
npm run start:ngrok
```

### Вариант 2: Быстро всё вместе (если нужно)

```bash
npm run dev:all
```

В отдельном терминале:
```bash
npm run start:ngrok
```

## 🌐 URLs для доступа

### Локально (только вы на ноутбуке)
- 🌐 Фронтенд: `http://localhost:3000/`
- 🔌 API: `http://localhost:3001/`
- 📡 WebSocket: `ws://localhost:3001`

### Удаленно (через ngrok)
- 🌐 Фронтенд: `https://cave.ngrok.app`
- 🔌 API: `https://cave.ngrok.app`
- 📡 WebSocket: `wss://cave.ngrok.app`

**⚠️ ngrok URL меняется при перезапуске!** Следите за выводом в терминале.

1. **Скажите им URL:**

2. **Они открывают в браузере** на любом устройстве (телефон, планшет, другой ноутбук)

3. **WebSocket автоматически подключится** к правильному бэкенду

4. **Игра синхронизируется** через WebSocket сервер

## 🔧 Переменные окружения (.env)

Эти значения **автоматически обновляются** при запуске `npm run start:ngrok`:

```env
VITE_APP_URL=https://cave.ngrok.app
VITE_API_URL=https://cave.ngrok.app
VITE_WS_URL=wss://cave.ngrok.app
```

Фронтенд использует эти переменные для подключения к правильным серверам.

## 🐛 Если что-то не работает

### WebSocket ошибка при ngrok
- ✅ Убедитесь что запущены **ОБА** туннеля (3000 и 3001)
- ✅ Проверьте что `VITE_WS_URL` содержит правильный ngrok URL
- ✅ Перезагрузите страницу в браузере

### Бэкенд не запускается
- ✅ Убедитесь что порт 3001 свободен: `netstat -an | findstr 3001`
- ✅ Если занят, убейте процесс: `taskkill /F /IM node.exe`

### ngrok не запускается
- ✅ Проверьте что `NGROK_AUTHTOKEN` в `.env` правильный
- ✅ Получите токен: https://dashboard.ngrok.com/get-started/your-authtoken
